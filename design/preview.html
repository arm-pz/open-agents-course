Context Engineering

Module 03 · all three tracks · prereq: 01, 02

Every step an agent takes costs tokens, and the window is finite. The model does not run out of intelligence at 180k tokens; it runs out of the ability to find what matters in the pile.[anth-ctx]

That is the whole subject: deciding what is in the window at each step, and what gets pushed out to a tool that can go fetch it again.[man-composition]

def compact(messages, threshold=120_000):
    if count_tokens(messages) < threshold:
        return messages
    head, tail = split_keep_first_and_last(messages)
    return [summarise(head)] + tail   # <- the common mistake, see below

The common mistake

Learners summarise the middle and keep everything else. Summarising is lossy in the direction that hurts: the earlier tool results are exactly where the agent’s failed attempts live.[ctx-rot-paper]

Foundations skips the code block and the exercise. Advanced gets the eval harness for measuring compaction loss.

05 · Spacing · layout · motion

Rules this page demonstrates

Base unit 8px, comfortable density. Prose measure capped at 66 characters. Border radius 4px on controls, 6px on cards — never pill-shaped except status pills. Sections on 64px vertical rhythm, divided by a 1px rule rather than by a shadow.

Motion is minimal-functional: a source chip changes background on hover, and a chip hover can reveal the source title. Entrance animation is limited to a 120ms opacity fade, disabled under prefers-reduced-motion.

Safe / risky

Safe: dark mode available, mono code blocks, left module nav, accessible contrast on a 1px-rule grid.

Risky: light paper as the default (all four peers measured default to dark); serif body prose; colour reserved for provenance only; right rail lists sources instead of a table of contents.
